# Third-party notice policy

Project Astra will keep launcher-owned code separate from third-party runtime, renderer, and compatibility components.

At this initial milestone, no source code from Zalith Launcher, PojavLauncher, Amethyst, MobileGlues, GL4ES, Mesa/Zink, Minecraft, or Mojang/Microsoft is included in the project tree.

Before any third-party component is vendored, linked, redistributed, or modified, its license and redistribution obligations must be reviewed and recorded here.
